01–06 / Experiments

One idea, tested
across six tools.

เลื่อนดูจากภาพที่ AI สร้าง ไปจนถึงกราฟ แผนภาพ เอกสาร สไลด์ และเว็บไซต์ ทุกหัวข้อใช้หลักฐานจากงานจริงและนำเสนอในรูปแบบเดียวกันเพื่อให้เปรียบเทียบได้รวดเร็ว

01

AI Image Generation

From a broad visual request
to a controlled composition.

ทดลองสร้างภาพ “สวัสดีวันจันทร์” และปรับรายละเอียดให้แมวมีแขน 2 ข้าง อยู่ในห้องเรียน และมีบรรยากาศสดใสขึ้น

Zero-shotPrompt 01
“ขอรูปสวัสดีวันจันทร์โดยใช้รูปนี้หน่อย”
RefinedPrompt 02
“แก้มือของแมวให้เหลือ 2 ข้าง เพิ่มบรรยากาศห้องเรียน และทำให้ภาพสดใสขึ้น”
What I learned

Zero-shot ให้ผลลัพธ์ที่ใช้งานได้ แต่รายละเอียดใน Prompt ช่วยควบคุมองค์ประกอบและลักษณะของภาพให้ตรงกับความต้องการเฉพาะเจาะจงมากขึ้น

Final reflection

Key Learning

“A good prompt does not only tell AI what to do.
It also defines the expected result.”

จากการทดลองพบว่า Zero-shot Prompt สามารถสร้างผลลัพธ์พื้นฐานได้ แต่เมื่อเพิ่ม Context, Requirements, Structure และ Expected Output ลงใน Prompt ผลลัพธ์จะตรงกับเป้าหมายมากขึ้น ลดการถามซ้ำ และนำไปใช้งานจริงได้ง่ายขึ้น

01

Context

ให้ข้อมูลพื้นฐานที่ AI จำเป็นต้องรู้

02

Requirements

ระบุสิ่งที่ต้องการอย่างชัดเจน

03

Structure

กำหนดรูปแบบและลำดับของผลลัพธ์

04

Expected Output

บอกให้ชัดว่าผลลัพธ์สุดท้ายควรพร้อมใช้งานอย่างไร

to a better result.
